حلقتا التكرار for و while في بايثون

كيف أتحقق من إجابتي؟

  1. افتح موقع بايثون على الإنترنت: online-python.com
  2. سيظهر في المحرر برنامج جاهز. امسحه كله: اضغط داخل المحرر ثم Ctrl + A ثم Delete.
  3. اكتب الكود الذي أمامك في السؤال (أو اضغط «نسخ الكود» ثم الصقه بـ Ctrl + V). انتبه للمسافات في بداية الأسطر.
  4. اضغط زر Run الأخضر.
  5. انظر إلى النتيجة التي ظهرت وقارنها بإجابتك. إن اختلفت، اقرأ الكود سطرًا سطرًا وحاول فهم الفرق.

اكتب إجابتك من تفكيرك أولًا، ثم تحقق منها بالموقع. إن كان الناتج عدة أسطر فاكتب كل سطر في سطر مستقل.

حلقة for

السؤال 1

for i in range(4):
    print(i)

السؤال 2

for i in range(2, 7, 2):
    print(i * 3)

حلقة while

السؤال 3

n = 1
while n <= 3:
    print(n)
    n = n + 1

السؤال 4

n = 10
while n > 0:
    print(n)
    n = n - 4
